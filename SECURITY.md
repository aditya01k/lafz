# Security

Please report security problems privately, not in a public issue:
use GitHub's **Report a vulnerability** button on this repository (Security tab → Advisories).

Include what you found, how to reproduce it, and what an attacker could do with it.
You'll get a reply within a few days. Please give us time to fix it before sharing details.

In scope: the code in this repository and the hosted app it runs (sign-in, credits and
payments, transcription). Out of scope: denial of service by volume, and third-party services
(Sarvam, OpenAI, Dodo Payments, Railway) themselves.

Self-hosting? Keep your `.env.local` private: it holds your own API keys.
